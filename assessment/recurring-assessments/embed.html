Recurring Assessment Types

Recurring assessment types are direct assessment tasks that appear multiple times across the program, deepening in scale, scaffolding, and stakes with each pass. Unlike signature assessments, which are single formal events, recurring types generate a continuous longitudinal evidence trail — the same kind of task, executed with increasing sophistication.

Each recurring type is associated with a primary sub-competency but typically generates evidence for multiple sub-competencies simultaneously.
