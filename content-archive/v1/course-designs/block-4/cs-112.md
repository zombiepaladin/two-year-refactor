## CS-112 — Algorithmic Thinking & Graphs

**1 credit**

### Working description

Students arrive knowing how to measure algorithmic cost (Big-O from CS-110) and implement hierarchical and hash-based structures (CS-110). This course extends in two complementary directions: algorithmic design strategy and graph foundations.

**Algorithmic design patterns.** Three canonical strategies as a mental toolkit: divide and conquer (break the problem, solve recursively, combine — mergesort and binary search as exemplars; recurrence relations as the analysis tool, building on MATH-103 recursion); greedy algorithms (locally optimal choices compose to global optimum — when this works and when it doesn't); introduction to dynamic programming (overlapping subproblems, memoization as the core insight — one worked example establishes the pattern). Optimization lens: algorithmic design as making a hard problem tractable by exploiting its structure.

**Graph foundations.** Graphs as the most general data structure — representing arbitrary relationships among entities, in contrast to trees (hierarchy only) and hash tables (no structure). Graph representations: adjacency matrix and adjacency list, trade-offs for dense vs. sparse graphs. Directed vs. undirected; weighted vs. unweighted; basic graph properties: connected components, cycles, paths. Fundamental traversal algorithms: breadth-first search (BFS) and depth-first search (DFS) — what each discovers, when to use each, and their relationship to the queue/stack abstractions students built in CS-109. This traversal vocabulary is the assumed foundation for CS-207 (B7), which returns to graphs for advanced optimization algorithms.

## Competency Assessments

| Assessment type | This pass | Competencies evidenced |
|---|---|---|
| Formal Analysis | Big-O analysis of divide-and-conquer algorithms via recurrence relations; formal graph property proofs (paired with MATH-104) | Apply Formal Reasoning |
| Algorithm Evaluation Task | Compare sorting algorithms by complexity for a specified scenario; select and justify graph representation (matrix vs. list) for a given problem structure | Evaluate Algorithmic Solutions; Represent Information |
| Implementation Task | Implement BFS and DFS on an adjacency-list graph; apply traversal to a concrete problem (e.g., reachability, connected components) | Implement Software Solutions |
| Reflection Assessment | Backward reflection — revisit an earlier data or algorithm decision (from B1/B2) and argue what you'd change now that you have Big-O and graph vocabulary | Reflect on Professional Growth |
