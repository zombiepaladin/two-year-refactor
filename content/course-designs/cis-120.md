## Course Description

The Internet, web browsers, and web-page-development technology: web-page design and implementation with Hypertext Markup Language (HTML), CSS, and JavaScript utilizing a modern webpage design. Students will also get hands-on experience deploying their own website.

## Course Overview

This course.  

## Course Goals and Learning Outcomes

1. Create valid HTML webpages using separation of concerns with HTML, CSS, and JavaScript.  
2. Design web pages with a focus on accessibility. 
3. Utilize CSS rules to create engaging and responsive web page designs. 
4. Use JavaScript to dynamically modify the structure and appearance of a webpage.  
5. Employ JavaScript to interact with Web APIs to exchange data.  
6. Think critically about web page design and apply industry standard web page design principles.
