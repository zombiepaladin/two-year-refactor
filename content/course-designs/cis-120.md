## Course Description 

The Internet, web browsers, and web-page-development technology: web-page design and implementation with Hypertext Markup Language (HTML), CSS, and JavaScript utilizing a modern webpage design. Students will also get hands-on experience deploying their own website. 

## Course Overview 

This course.  

## Course Goals and Learning Outcomes 

- Create valid HTML webpages using separation of concerns with HTML, CSS, and JavaScript.  
- Design web pages with a focus on accessibility. 
- Utilize CSS rules to create engaging and responsive web page designs. 
- Use JavaScript to dynamically modify the structure and appearance of a webpage.  
- Employ JavaScript to interact with Web APIs to exchange data.  
- Think critically about web page design and apply industry standard web page design principles.

None/varies by topic. Instructor permission required.
