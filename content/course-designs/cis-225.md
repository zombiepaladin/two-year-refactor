## Course Description

Survey of computer networking fundamentals, including 7-layer OSI model, common networking protocols, stream-based and message-based network programming, network security, and network performance and reliability basics.
## Credit Hours

1 credit

## Course Overview

This course will introduce students to the core concepts of network communication between computing systems. Students will learn about the 7-layer OSI network model and how common networking protocols such as TCP/IP, HTTP, DHCP, DNS, and more work to form the foundation of the modern internet. Students will explore basic socket-based network programming, discuss security of network communications, and explore concepts related to network performance and reliability. ## Course Goals and Learning Outcomes
1. Explain the 7-level OSI model, and discuss where various protocols sit within that model
2. Describe how data is encapsulated into packets for transmission
3. Construct a working socket-based networked system such as a chat server
 and client
4. Differentiate between common networking protocols and their uses
5. Explain security requirements for different network communication
6. Describe the distributed structure of the internet
7. Examine network performance and reliability metrics
