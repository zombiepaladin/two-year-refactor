## Course Description

A new course created for the two-year core redesign — no existing K-State catalog entry. The confirmed, formalized home for authentication and authorization, threat modeling, and applied cryptography.

## Credit Hours

1 credit (per `resources/reference/degree-maps/cs.md`)

## Course Overview

Not yet drafted as a full syllabus, but the redesign rationale is well-documented — see `resources/reference/degree-maps/cs.md`'s CIS 251 entry in full. Summary: applied cryptography ties to MATH — Recursive and Modular Computation (modular arithmetic, Euclid's algorithm), correctly sequenced earlier in the core. Reinforced same-semester by the CIS 300/CIS 320 client-server pairing (protecting server endpoints, consuming protected APIs) and later by CIS 400's capstone, which needs real contributor accounts distinguishing historian/community-contributor edit rights from public viewing. This is the program's confirmed primary ABET ethics anchor — see the Trustworthy Computing lens (`content/core-design/lenses/lens-trustworthy-computing.md`).
