## Course Description

This 1‑credit hour course introduces students to Structured Query Language (SQL) for retrieving and analyzing data in relational databases. Students will learn to write basic queries to select, filter, summarize, and combine data from multiple tables using hands‑on exercises and real‑world examples.

## Credit Hours

1 credit

## Course Overview

The objective of this course is to provide students with the foundations to understand simple relational databases. With this knowledge, students will be able to understand and write SQL queries to find, organize, and summarize information from real-world datasets.

## Course Goals and Learning Outcomes

1. Explain the purpose of SQL and how relational databases are used to store and retrieve structured data.
2. Write basic SQL queries using (but not limited to) SELECT, FROM, and WHERE to retrieve specific data from a relational database.
3. Sort and filter query results using ORDER BY, comparison operators, and logical operators.
4. Summarize data using aggregate functions, such as COUNT, SUM, AVG, MIN, MAX, with GROUP BY.
5. Combine data from multiple tables using basic JOIN operations.
6. Write SQL queries that modify data in an existing database, such as INSERT, UPDATE, and DELETE
7. Use programmable objects to create meaningful transformations of data, such as VIEWS and table expressions.
8. Employ advanced SQL techniques, like sub queries, to answer more complex questions
9. Interpret query results to answer practical, real‑world questions.
10. Demonstrate understanding of basic relational database design

## Assignmetns Overview

This course will consist of primarily lab exercises that will be completed during in-class labs, along with some take-home practice assignments. The course will conclude with an in-class practical to showcase understanding of the material.

- Labs: 60%
