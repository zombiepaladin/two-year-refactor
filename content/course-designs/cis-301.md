## Course Description

Logical formalisms used to model and reason about computer systems. Propositional and predicate logic, syntax, semantics, and proof theory; soundness and completeness issues. Mathematical induction. Program verification: invariants and program logics.

## Credit Hours

2 credits

## Course Overview

This course provides an introduction to formal logic and its application to mathematical reasoning and software correctness. Students will learn to represent and analyze logical statements using propositional and predicate logic, evaluate arguments and proofs, and apply formal reasoning techniques such as equivalence laws, deduction rules, contradiction, and induction. Topics include truth tables, sets, quantifiers, logical proofs, and the translation of natural language into formal symbolic expressions. The course also examines the use of logic in computing, with an emphasis on reasoning about program correctness through specifications, preconditions, postconditions, invariants, loops, functions, and program termination. By the end of the course, students will be able to apply formal methods to analyze logical arguments and verify the correctness of computational systems.

## Course Goals and Learning Outcomes

1. Represent and analyze logical statements using formal symbolic notation, including propositional and predicate logic.
2. Translate between natural language and formal logical expressions to model statements, arguments, and relationships precisely.
3. Evaluate the validity of logical arguments using truth tables, equivalence laws, counterexamples, and formal deduction techniques.
4. Construct rigorous mathematical and logical proofs using direct proofs, conditional proofs, proof by contradiction, and mathematical induction.
5. Apply set theory, quantifiers, and formal reasoning techniques to analyze mathematical and computational problems.
6. Use formal methods to reason about the correctness of programs, including assignments, conditionals, loops, functions, arrays, and program termination.
7. Develop and apply specifications, preconditions, postconditions, invariants, and loop invariants to verify software behavior and correctness.
8. Analyze and communicate logical arguments and correctness proofs using appropriate formal notation and terminology.

## Course Schedule

This course is an introduction to formal logic. We will learn how to express claims using special syntax, and will learn rules for making deductions about those claims. In the second half of the course, we will apply our formal logic tools towards reasoning about program correctness. In particular, we will cover:
- Logic puzzles and basic logical reasoning
- Truth tables
- Circuits and parse trees
- Propositional logic, including:
  - Translating English claims into propositional logic
  - Equivalences
  - Valid and invalid arguments in propositional logic; counterexamples
  - Natural deduction rules and proofs in propositional logic
  - Soundness and completeness
- Sets
- Predicate logic, including:
  - Quantifiers
  - Translating English claims into predicate logic
  - Equivalences
  - Valid and invalid arguments in predicate logic; counterexamples
  - Natural deduction rules and proofs in predicate logic
- Types of proofs
  - Conditional proofs
  - Proof by contradiction
  - Proof by induction
- Programming logic, including reasoning about correctness involving:
  - Assignment operations
  - Conditional statements
  - Loops (including loop invariants)
  - Functions/procedures (including pre- and post-conditions and function specifications)
  - Arrays
  - Global invariants
  - Termination
  - Function specifications in practice
