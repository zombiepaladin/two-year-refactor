## Course Description

Basic inter-process communication and network programming concepts including client-server and peer-to-peer, communication protocol use and specification, reliable and secure communication, and network applications including web technologies, electronic mail, and file transfer with a focus on application and implementation.

## Credit Hours

3 credits
