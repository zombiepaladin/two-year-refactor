CIS 141 - AI/Data Science

Course Description

A new course created for the two-year core redesign — no existing K-State catalog entry.

Credit Hours

1 credit (per resources/reference/degree-maps/cs.md)

Course Overview

Not yet drafted as a full syllabus. resources/reference/degree-maps/cs.md confirms this as the natural home for GPU and TPU content specifically, completing a CPU (seeded in CIS 115) → CPU-vs-GPU parallel execution contrast (CIS 200/300) → GPU/TPU-for-AI escalation: why AI/ML training leans on GPUs and TPUs (matrix-multiplication-heavy, data-parallel work these architectures accelerate directly). Conceptual/awareness-level, not a hardware-programming unit. This is also the confirmed terminal pass for the AI-Assisted Development bounded practice — see content/core-design/threads/practice-ai-assisted.md — where students critique AI-generated code for correctness and security as a prerequisite skill for the Year 3–4 Agentic AI specialization.
