CIS 200 - Programming Fundamentals

Course Description

Principles of algorithm design and their application to procedural programming: state, control structures, methods. Patterns of conditional and iterative control structure. Program testing. Introduction to arrays, classes, and objects. Programming projects.

Credit Hours

3 credits

Course Overview

Learn the fundamentals of writing computer programs  – specific instructions in a language that the computer can understand.  Every computer application you use and every interactive website you visit is the result of a computer program.  In this class, we will learn to write computer programs in Java and C# – however, the skills we will develop will apply to all programming languages.

Course Goals and Learning Outcomes

Upon completion of this course, students will be able to:

  1. Explain and apply core object-oriented programs principles, including subclasses, encapsulation, inheritance, and abstraction.
  2. Develop robust programs by implementing error-handling techniques, including exception handling, in object-oriented programs.
  3. Enumerate the differences between imperative and object-oriented programming paradigms.
  4. Compose a class through design, implementation, and testing to meet behavioral requirements.
  5. Demonstrate knowledge and use of object-oriented programming, collection classes, and iterators and apply them effectively in problem-solving.
  6. Use structured problem-solving techniques to decompose complex problems and develop effective, efficient solutions through object-oriented programming principles.
