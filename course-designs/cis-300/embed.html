CIS 300 - Data and Program Structures

Course Description

A study of common data and program structures together with associated algorithms. Topics include interfaces, design patterns, and common data structures (such as arrays, stacks, queues, lists, trees, graphs, hash tables), as well as common algorithms that utilize these structures. Students will gain experience with both use and implementation of these structures and algorithms using a modern programming language. Students will also learn the various tradeoffs involving performance and software maintainability in data structure choice.

Credit Hours

3 credits

Course Overview

This course examines the fundamental data structures, algorithms, and software design principles used in modern computing. Students will learn to analyze, implement, and apply common data structures such as arrays, stacks, queues, lists, trees, graphs, hash tables and more, along with the algorithms that operate on them. Through hands-on programming experiences, students will explore interfaces, abstraction, and design patterns while developing solutions to computational problems and data structures. Emphasis is placed on evaluating algorithm efficiency, understanding performance tradeoffs, and selecting appropriate data structures to create efficient and maintainable software.

Course Goals and Learning Outcomes

  1. Write programs which implement and use abstract and reference-type data structures, including, but not limited to:

    • Strings and string parsing (and related structures like string builders)
    • Lists and arrays
    • Linked lists
    • Stacks
    • Queues and priority queues
    • Trees (including, but not limited to binary search trees, AVL trees, and tries)
    • Sets
    • Hash tables
    • Dictionaries
    • Heaps
    • Graphs

  2. Select and use appropriate data structures to solve real-world problems.

  3. Understand and explain how the performance of a program may change based on the data structure chosen.

  4. Implement and apply algorithms for searching, sorting, and manipulating a data structure.

  5. Understand and use fundamental algorithms for data structures listed in SLO #1, including, but not limited to:

    • Standard sorting/search algorithms (e.g., insertion sort, merge sort, quicksort, etc.)
    • Advanced sorting/searching algorithms (e.g., Dijkstra’s algorithm, greedy algorithms, bucket sort, radix sort, etc.)
    • Tree algorithms
    • Graph algorithms
    • Recursive and iterative algorithms

  6. Analyze performance differences and complexity between various algorithms and data structures as outlined in SLO #1.

  7. Utilize advanced object-oriented concepts, such as generics, interfaces, indexers, and enumerators, to implement or partially implement data structures.

Assignments

Student performance is assessed through review quizzes, lab assignments, homework projects, and exams. Review quizzes help prepare students for upcoming labs and may be taken twice, with the higher score recorded. Weekly lab assignments provide hands-on programming experience and must be completed during the lab period for credit. Large programming homework assignments are completed throughout the semester, with the final assignment serving as a comprehensive project. Students will also complete coding-based exams. Together, these assessments emphasize preparation, participation, programming practice, and mastery of data structures and algorithms.
