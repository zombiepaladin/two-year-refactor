CIS 320 - User Experience Development

Potential new course to be developed. Initial offering would focus on vue as a component-based UX library for the web. Serves as part of a three-course progression, CIS 120 → CIS 220 → CIS 320. May need to be merged with CIS 220 to minimize staffing requirements.

Course Description

Building user-facing interfaces using a component-based architecture, consuming data from a provided service layer, with an introduction to validating a design against user needs. Sections focus on a specific platform (e.g. web, mobile, desktop); consult the section syllabus for the platform and tools used. (Proposed catalog description, per resources/reference/degree-maps/cs.md.)

Credit Hours

1 credit (per resources/reference/degree-maps/cs.md)

Course Overview

Reframed 2026-07-15 — generic catalog identity, specific curriculum design. Same treatment as CIS 220: catalog identity is platform-agnostic; the two-year core runs the Web section. This is CIS 300’s deliberate pair: same client/server system boundary, opposite side — this course is the client (consuming APIs from a provided/external server), CIS 300 is the server. Deepens CIS 120’s HTML/CSS/JS seed with a component-based UI library (not yet chosen). Includes one bounded exposure to acceptance-criteria/A-B-testing process work — a full deep dive is planned as a Software Architecture specialization elective instead. See resources/reference/degree-maps/cs.md’s CIS 320 entry for full detail.

Course Goals and Learning Outcomes

Proposed catalog learning outcomes (generic, per cs.md): build a user interface from reusable, composable components; consume data from a provided service/API layer to populate and update an interface; apply accessibility and usability standards to an interface design; evaluate a design against a stated set of acceptance criteria. Web-section-specific outcomes not yet drafted.
