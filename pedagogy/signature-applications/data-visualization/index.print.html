What it is

“Where Did They Go?” (repo: github.com/ksu-cs/development-project-ksds) is an active external project — Vue + JavaScript + D3.js frontend, Node.js backend, static JSON/GeoJSON data, MIT license, 12+ releases as of mid-2026. It’s a partnership between K-State CS and the Chapman Center for Rural Studies (History department), visualizing rural population migration in Kansas — county borders, rail/interstate infrastructure, Army Corps of Engineers lakes, town populations, hospitals, schools — with playback over time.

Being built for eventual multi-state reuse, not Kansas-only (confirmed 2026-07-15) — worth keeping in mind before treating any Kansas-specific framing as permanent.

This is a consumption/context asset, not a student build target. Per the confirmed CIS 400 capstone design, student teams do not modify this codebase directly — it’s a live external project with its own release cadence and non-CS stakeholders (Chapman Center historians). It’s used as motivating context and a data-consumption source, not something student teams ship changes to.

Relationship to the historical archive

“Where Did They Go?” consumes static files generated by a separate, not-yet-built system — the historical archive — which is where the community-facing correction/versioning/search work (and CIS 400’s actual capstone project) lives. Treat the two as coupled but distinct: this page’s asset is the existing, external, read-mostly visualization; the historical archive is the green-field system student teams help build.
