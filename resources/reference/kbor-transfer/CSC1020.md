# CSC1020 – Programming Fundamentals
Course Effective Date: Summer 2025
Outcome Approval Date: Fall 2024
Next Outcome Review Date: Fall 2029

## Transfer Equivalency
This course transfers as CIS 116.

## Student Learning Outcomes
Upon completion of this course, students will be able to:
1. Explain key programming concepts such as variables, data types, control structures, functions, arrays.
2. Design and implement basic algorithms for solving common computational problems. Students will be able to write, test, and debug programs using appropriate syntax and best practices in a programming language (e.g., Python, Java, C++).
3. Demonstrate proficiency in using conditional statements (if-else) and loops (for, while) to control program flow.
4. Create and use functions to organize and modularize code, applying principles of reusability and abstraction.
5. Write programs that handle basic user input and display output, including file I/O operations.
6. Demonstrate knowledge of fundamental data structures, such as arrays and/or lists, and apply them effectively in problem-solving.
7. Use structured problem-solving techniques to decompose complex problems and develop effective, efficient solutions through programming
