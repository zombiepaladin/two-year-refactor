# CIS 200 — Programming Fundamentals

**Credits:** 4
**Typically offered:** Fall, Spring

Principles of algorithm design and their application to procedural programming: state, control structures, methods. Patterns of conditional and iterative control structure.  Program testing. Introduction to arrays, classes, and objects.  Programming projects.

Prerequisites: CIS 116 (Intro to Programming) and either MATH 205 (General Calc) or Math 220 (Calc I) (either can also
be taken concurrently with CIS 200) with a minimum grade of ‘C’ in each. These prerequisites are considered essential to
student success in the course. If you do NOT have these prerequisites, you should only be in this class with explicit
permission granted by the Professor or CS Department. To successfully develop computer programs, students are expected
to have the advanced logical thinking skills that come from applying techniques to solve mathematical problems.
Since CIS 116 (Intro to Programming w/Python) is a pre-req for the course, previous programming experience is assumed.
This is NOT Introduction to Computer Programming. Non-majors interested in programming (and those who find 
themselves struggling) might consider CC 111: Elements of Computer Programming, a 1-credit hour, 100-level course that 
moves at a much slower pace and does not cover as much material (counts as an unrestricted elective for CS majors).
CIS 200 is Programming Fundamentals, a 200-level course intended for Computer Science and Computer Engineering
majors. The primary goal is to not only teach Programming Fundamentals, but to prepare students to be successful in the
subsequent course (CIS 300).
While those with minimal previous programming experience CAN be successful in this course, it requires you to work
harder and to seek help more often, just as those with weaker math skills usually need outside help/tutoring in Calc I,
compared to someone with a strong math background and previous experience with Calculus.
CIS 200 satisfies the Empirical & Quantitative Reasoning tag of the K-State 8 Gen Ed program. As part of this course, you 
will develop skills for writing programs through the application of appropriate strategies and use of logical reasoning skills.
Objectives: Learn the fundamentals of writing computer programs primarily using the Java programming language (C# is
briefly introduced at the end of the course). The skills developed in this course are transferable to subsequent programming
language courses. Specifically, the following topics will be covered:
Weeks 1-4: Command Line Compiling vs. using an IDE (Eclipse); Introduction to Java/JVM; Variables and Arithmetic 
Operations; Displaying Output; User Input; Conditional statements; Loops; Arrays; Strings
Weeks 6-10: Reading from/writing to text files; Pre-built/Programmer-defined Methods; Searching/Sorting Algorithms; 
Command Line Arguments; Variable Length Parameters; Classes and Objects; Overloaded Methods; 
Cryptography; Program Design with MVC (Model-View-Controller) Architecture
Weeks 12-15: Exception Handling; Collection Classes (ArrayLists, TreeSets, and HashMaps); Comparing Java .vs C#; 
creating a GUI in C# using Visual Studi
