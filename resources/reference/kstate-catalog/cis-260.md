# CIS 260 – Foundations of Relational Databases - Syllabus

## Course Description

This 1‑credit hour course introduces students to Structured Query Language (SQL) for retrieving and analyzing data in relational databases. Students will learn to write basic queries to select, filter, summarize, and combine data from multiple tables using hands‑on exercises and real‑world examples.

## Course Overview

The objective of this course is to provide students with the foundations to understand simple relational databases. With this knowledge, students will be able to understand and write SQL queries to find, organize, and summarize information from real-world datasets.

## Learning Objectives

- Explain the purpose of SQL and how relational databases are used to store and retrieve structured data.

- Write basic SQL queries using (but not limited to)`SELECT`, `FROM`, and `WHERE` to retrieve specific data from a relational database.

- Sort and filter query results using `ORDER BY`, comparison operators, and logical operators.

- Summarize data using aggregate functions, such as`COUNT`, `SUM`, `AVG`, `MIN`, `MAX`, with `GROUP BY`.

- Combine data from multiple tables using basic `JOIN` operations.
- Write SQL queries that modify data in an existing database, such as `INSERT`, `UPDATE`,  and`DELETE`
- Use programmable objects to create meaningful transformations of data, such as `VIEWS` and table expressions.
- Employ advanced SQL techniques, like sub queries, to answer more complex questions 

- Interpret query results to answer practical, real‑world questions.
- Demonstrate understanding of basic relational database design.
