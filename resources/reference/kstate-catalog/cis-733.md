# CIS 733 — Data Science Foundations

**Credits:** 3
**Typically offered:** Fall

Methods used for making discoveries in complex data and turning data into knowledge. Handling big data and ""small data"", feature engineering, convolutions, classification, regression, using clustering for discovery, novelty detection, statistical inference, research design, prescriptive analytics, and more. Using standard software packages and libraries for preparing and analyzing data, implementing supervised machine learning, and visualization.
